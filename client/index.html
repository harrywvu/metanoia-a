How It Works

Motion capture, packaged for production.

Metanoia takes your source clip through a compact motion-processing pipeline built for speed and usable output. We use VIBE for human pose estimation, transform the recovered motion in Blender, and export both FBX and glTF for game engines, DCC tools, and review workflows.

Finished assets are stored on Cloudflare R2 so they can be delivered quickly to the viewer and download actions in the app.

When your motion capture finishes, we send a rich Discord notification with download links. You can set up a webhook to get real-time updates in your server.

About

Metanoia is a creator-facing motion workflow.

The project is focused on turning ordinary video into clean, reusable animation with less setup friction. The interface stays minimal so the work stays centered on input quality, processing status, and export readiness.

Team Metanoia is building the experience end to end: ingestion, processing, storage, and delivery. The goal is a pipeline that feels approachable for creators without flattening the technical depth underneath it.
